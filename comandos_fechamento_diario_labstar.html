Comandos de Fechamento Diário — Labstar Cyber Arena

Arquivo para guardar e usar no final de cada dia da feira.

Resumo rápido

No final de cada dia você usa estes comandos nesta ordem:
  1. Copiar os telefones do ranking para participantes_evento.
  2. Arquivar o ranking do dia em ranking_historico.
  3. Conferir se os dados foram copiados.
  4. Limpar somente a tabela ranking.

Importante: o que cada tabela faz

  • ranking: ranking exibido na TV/painel do dia atual. Esta tabela pode ser limpa no final de cada dia.
  • participantes_evento: lista de telefones que já participaram na feira inteira. Esta tabela NÃO deve ser limpa durante os 4 dias reais.
  • ranking_historico: histórico/backup dos participantes de cada dia. Esta tabela NÃO deve ser limpa durante a feira.
Nunca apague durante a feira real:
participantes_evento e ranking_historico.
No final de cada dia real, limpe somente ranking.

Comando 1 — Marcar participantes do dia como já participantes da feira

Este comando copia nome e telefone do ranking para participantes_evento. Isso mantém o bloqueio nos próximos dias, mesmo depois de limpar o ranking diário.

INSERT INTO participantes_evento (
  nome,
  telefone,
  primeiro_dia
)
SELECT
  nome,
  telefone,
  CURRENT_DATE
FROM ranking
ON CONFLICT (telefone) DO NOTHING;

Comando 2 — Arquivar ranking do dia no histórico

Este comando copia o ranking completo do dia para ranking_historico.

INSERT INTO ranking_historico (
  nome,
  telefone,
  forca,
  tempo_estimado,
  tempo_valor,
  cyber_score,
  analise_resumo,
  sugestoes_resumo,
  timestamp,
  dia_evento
)
SELECT
  nome,
  telefone,
  forca,
  tempo_estimado,
  tempo_valor,
  cyber_score,
  analise_resumo,
  sugestoes_resumo,
  timestamp,
  CURRENT_DATE
FROM ranking;

Se fechar depois da meia-noite

Se você rodar o fechamento depois da meia-noite, CURRENT_DATE pode registrar o dia seguinte. Nesse caso, use a data manual do dia da feira.

Exemplo com data manual:

INSERT INTO ranking_historico (
  nome,
  telefone,
  forca,
  tempo_estimado,
  tempo_valor,
  cyber_score,
  analise_resumo,
  sugestoes_resumo,
  timestamp,
  dia_evento
)
SELECT
  nome,
  telefone,
  forca,
  tempo_estimado,
  tempo_valor,
  cyber_score,
  analise_resumo,
  sugestoes_resumo,
  timestamp,
  '2026-05-21'::date
FROM ranking;

Comando 3 — Conferir se copiou para participantes_evento

SELECT COUNT(*) AS total_participantes_evento
FROM participantes_evento;

Para ver os últimos registrados:

SELECT *
FROM participantes_evento
ORDER BY criado_em DESC;

Comando 4 — Conferir se arquivou no histórico

SELECT COUNT(*) AS total_arquivado_hoje
FROM ranking_historico
WHERE dia_evento = CURRENT_DATE;

Se você usou data manual, confira com a mesma data:

SELECT COUNT(*) AS total_arquivado_dia
FROM ranking_historico
WHERE dia_evento = '2026-05-21'::date;

Comando 5 — Limpar somente o ranking do dia

Rode este comando somente depois de confirmar que os dados foram copiados para participantes_evento e ranking_historico. 
TRUNCATE TABLE ranking;

Sequência completa para final de dia real

Use esta sequência quando o dia da feira terminar. 
-- 1. Copiar telefones para bloqueio da feira inteira
INSERT INTO participantes_evento (
  nome,
  telefone,
  primeiro_dia
)
SELECT
  nome,
  telefone,
  CURRENT_DATE
FROM ranking
ON CONFLICT (telefone) DO NOTHING;

-- 2. Arquivar ranking do dia
INSERT INTO ranking_historico (
  nome,
  telefone,
  forca,
  tempo_estimado,
  tempo_valor,
  cyber_score,
  analise_resumo,
  sugestoes_resumo,
  timestamp,
  dia_evento
)
SELECT
  nome,
  telefone,
  forca,
  tempo_estimado,
  tempo_valor,
  cyber_score,
  analise_resumo,
  sugestoes_resumo,
  timestamp,
  CURRENT_DATE
FROM ranking;

-- 3. Conferir participantes bloqueados
SELECT COUNT(*) AS total_participantes_evento
FROM participantes_evento;

-- 4. Conferir histórico do dia
SELECT COUNT(*) AS total_arquivado_hoje
FROM ranking_historico
WHERE dia_evento = CURRENT_DATE;

-- 5. Limpar somente o ranking diário
TRUNCATE TABLE ranking;

Para teste/demonstração antes da feira

Se for apenas teste e você quiser repetir com as mesmas pessoas na segunda-feira, pode apagar a tabela participantes_evento depois da demonstração. Não faça isso durante a feira real. 
DELETE FROM participantes_evento;

Se também quiser apagar os testes do ranking:

DELETE FROM ranking
WHERE DATE(timestamp) = CURRENT_DATE;

Se você arquivou testes no histórico e quiser limpar apenas os testes de hoje:

DELETE FROM ranking_historico
WHERE dia_evento = CURRENT_DATE;

Checklist final do dia

  • Copiei ranking para participantes_evento.
  • Copiei ranking para ranking_historico.
  • Conferi a contagem do histórico.
  • Conferi a contagem dos participantes bloqueados.
  • Limpei somente ranking.
  • Não apaguei participantes_evento durante a feira real.
  • Não apaguei ranking_historico durante a feira real.

Resumo final

Final de cada dia real:
1. ranking → participantes_evento para bloquear participação repetida.
2. ranking → ranking_historico para guardar o histórico do dia.
3. TRUNCATE ranking para zerar a TV/ranking do próximo dia.

Durante os 4 dias reais, não limpar: participantes_evento e ranking_historico.
